# 需求 · 对照布局与面板显隐

## 背景

Review 时需要「diff / 需求概设 / 飞书 PRD / TaskBoard 工具窗」同屏协作，且各面板可随时收起。
本文档由用户实际使用中的多轮反馈迭代成型，记录最终形态与诉求对应关系。

## 功能点（用户原始诉求 → 现状）

| 诉求 | 实现 |
|---|---|
| 一键铺排 | **「对照布局」**：左 diff（宽可调）+ 右列（需求概设 ⇄ 飞书 PRD 双 tab）+ TaskBoard 停靠底部（高可调）；铺前自动清场（tab/分屏不堆积） |
| 右列内容切换 | 两个 tab 直接点切换（原「文档/PRD」按钮因冗余已删） |
| 面板显隐 | 顶栏 **「☑ diff」「☑ 文档」开关**（勾选=显示、状态实时反映真实状态） |
| 比例自定义 | **「布局设置」**对话框（diff 宽度 30–85% / TaskBoard 高度 15–50%）；拖分隔条自动记忆（应用级持久化） |
| 收起后不打扰 | 收起文档后**焦点落回 diff**（不跳无关文件）；显隐开关**互不连带** |
| 节点树快捷操作 | 树顶**按钮行**：拷贝上下文 / 拷贝节点ID / 搜索定位（另有刷新） |

## 边界

- **「对照布局」是唯一会动整体布局的入口**；显隐开关只动各自面板（不重铺、不连带）
- 收起文档会清理「飞书 PRD 相关的一切 tab」（含用户点 PRD 链接产生的网页 tab）
- 收起时**不关**用户自己打开的源码 tab（如从文件树双击的 DetailView.vue）——只把焦点让回 diff

## 验收

- 反复点「对照布局」：tab/分屏数量恒定（diff 1 + 文档 1 + PRD ≤1）
- 取消「文档」：右列消失、飞书相关 tab 一个不剩；再勾选：右列重建（双 tab）
- 取消「diff」→ 勾选：只出现 diff（文档保持原状态）
- 收起文档：焦点在 diff 上（不跳别的文件）
- 「布局设置」改比例 → 已铺布局即时生效；重启 IDEA 后仍生效
