# 功能：表格式展开树（Web UI）

## 所属计划

计划 3。

## 需求

- 表格式展开树，整树一次加载、按行展开/收起
- 名称搜索 + 类型/状态筛选
- 行悬浮操作：新增子节点、删除
- 右侧详情抽屉（el-drawer）显示基本信息、属性、文档、子节点、commit 登记
- 文档区：左列文档名列表 + 右侧 markdown 编辑/预览
- setttings 页：配置 GitLab 地址/Token、端口

## 验收标准

- `npm run build` 构建成功
- `npm start` 后浏览器访问能看到树形表格
- 新建项目、新增子节点、删除节点操作正常
- 右侧抽屉展示节点详情与属性表单
- 文档新增/编辑/删除/预览正常
